Sensate

Browser tools for the WITMOTION WT901BLE IMU. Connect over Web Bluetooth, record live IMU, and export CSV — no app install, no backend.
Chrome or Edge on desktop • HTTPS • Web Bluetooth
Lower back / pelvis

Gait Analyzer

Live cadence, step timing, variability, and a walking simulation. Firm placement on the lower back or pelvis; keep orientation fixed for the whole walk.
Hand / wrist

Hand Gestures

Record and detect Rest, Wave, Flick, Punch, and Twist from a sensor on the back of the hand or wrist. Manual labels, simulation, and CSV export for training takes.
Use Chrome or Edge on a desktop OS. Web Bluetooth is not available in Firefox or Safari. GitHub Pages serves this site over HTTPS, which the Bluetooth API requires. Filter for devices named with prefix WT.
